# Restaurant Portal Documentation

## 1. Project Overview
Restaurant Portal is a comprehensive, modern, and secure web application designed for restaurant management and food delivery. It supports multiple roles including Customers, Restaurant Owners, Delivery Boys, and Administrators.

## 2. Technology Stack
- **Frontend Framework:** Next.js (version 16.3.6)
- **UI Library:** React.js (version 19.2.8)
- **Styling:** Tailwind CSS (version 4)
- **Icons:** Lucide React
- **Database Backend:** Supabase (PostgreSQL)
- **Authentication:** Supabase Auth, Firebase Auth (integrated as per package.json), JSON Web Tokens (JWT), and bcryptjs.
- **Language:** TypeScript

## 3. Features
1. **Authentication:**
   - Multi-role login and registration (Customer, Owner, Delivery, Admin).
   - Secure routing and client-side protection.
   - OTP verifications and password hashing.
2. **User Interface:**
   - Modern Hero Section.
   - Global Header with Search and Profile features.
   - Collapsible Left Sidebar for navigation.
   - Fully responsive design using Tailwind CSS.
3. **Core Modules:**
   - **Menu & Orders:** Categories, Menu Items (Variants & Addons), Cart, and Order placement.
   - **Restaurant Management:** KYC for Owners, Restaurant details, Restaurant Tables, and Table Bookings.
   - **Delivery System:** Delivery Boy KYC, Order Assignments, Tracking.
   - **Promotions:** Coupons and Banners.
   - **Subscriptions & Party Orders:** Tiffin subscription models and party/bulk orders enquiry.

## 4. Database Architecture (Key Tables)
The database schema consists of several interconnected tables mapped out for scalability:
- `users`: Core table handling all roles (customer, owner, delivery_boy, admin) and their authentication details.
- `otp_verifications`: Manages OTP-based verification for login and sign-ups.
- `owner_kyc_details` & `delivery_boy_kyc_details`: Manages regulatory details (FSSAI, Aadhar, PAN, vehicle details).
- `restaurants`: Core restaurant profiles.
- `categories` & `menu_items` (with `item_variants` & `item_addons`): Manages the diverse food menu catalog.
- `orders`, `order_items`, & `carts`: Manages the checkout and order lifecycle.
- `restaurant_tables` & `table_bookings`: Manages dine-in experiences.
- `subscription_plans` & `subscriptions`: Manages recurring meal plans (tiffin).
- `party_orders`: Bulk booking inquiries.

## 5. Deployment Instructions
The application is structured to be seamlessly deployed on Vercel:
1. Initialize a Supabase project and gather the `URL` and `Anon Key`.
2. Add these environment variables in the `.env.local` file (for local development) and in Vercel's Environment Variables settings.
3. Deploy directly via GitHub integration on Vercel.
